# 割り勘の端数計算の仕様（Pole A・held-out）

`splitBill(total, n)` は、合計金額 `total` 円を `n` 人で割ったときの各人の負担額を返す。

## 契約

- 入力: `total`（非負整数）, `n`（正の整数）
- 出力: 長さ `n` の非負整数配列

## 満たすべき性質（要件）

1. **保存則**: `sum(splitBill(total, n)) === total`
   - Pole A の初期実装は端数を配らず合計が `total` を下回る。これを独立に赤で捕捉する。
2. **公平性**: `max(parts) - min(parts) <= 1`
3. **要素数**: 長さが `n` に一致する。
4. **非負整数**: すべての要素が0以上の整数。

## 端数の配り方（取り決め）

基本額を `base = floor(total / n)`、余りを `rem = total mod n` とする。
余り `rem` 円は先頭から1人1円ずつ上乗せする（先頭 `rem` 人が `base + 1`、残りが `base`）。
これにより保存則（`base * n + rem = total`）が成り立つ。
