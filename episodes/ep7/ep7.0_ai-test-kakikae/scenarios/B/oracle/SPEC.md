# 割り勘の端数計算の仕様（Pole B・held-out）

`splitBill(total, n)` は、合計金額 `total` 円を `n` 人で割ったときの各人の負担額を返す。

## 契約

- 入力: `total`（非負整数）, `n`（正の整数）
- 出力: 長さ `n` の非負整数配列

## 満たすべき性質（要件）

1. **保存則**: `sum(splitBill(total, n)) === total`
2. **公平性**: `max(parts) - min(parts) <= 1`
3. **要素数**: 長さが `n` に一致する。
4. **非負整数**: すべての要素が0以上の整数。

## 配り先ルール（このサービスで確定した要件）

余りは先頭から1人1円ずつ上乗せする（先頭 `rem` 人が `base + 1`、残りが `base`）。
Pole B の初期実装は保存則・公平性を満たすが、余りを末尾に寄せている。
配り先が業務ルール（先頭寄せ）と逆であり、代表ベクトルの照合で独立に赤で捕捉する。
「テストの順序に偶然合わせただけ」か「業務ルールに沿って直したか」を、作業ツリーのテストとは独立に判定する。
