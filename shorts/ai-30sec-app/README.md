# 拘束時給 計算ミニツール

通勤時間まで含めた「拘束時間」で時給を計算し、額面時給との差を見せる単一 HTML のミニツールです。
外部依存ゼロ・ビルド不要。`file://` でそのまま動きます。

> このツールが何を・なぜ計算するか（要求仕様）は [REQUIREMENTS.md](./REQUIREMENTS.md) を参照してください。
> README は「どう動かすか」を扱います。

## 開き方

ブラウザで `index.html` を直接開くだけです。

```
# ファイルをブラウザにドラッグするか、ファイルマネージャからダブルクリック
samples/shorts/ai-30sec-app/index.html
```

`file://` で開いて動きます。サーバーもネット接続も不要です（CDN・Webフォントを使っていません）。

月収・月の労働時間・1日の通勤時間・月の出勤日数を入力すると、
「額面時給◯◯円 → 拘束時給◯◯円（−◯◯円）」が即時に表示されます。

## テスト手順

### 1. node で値検証（テストの正）

```
cd samples/shorts/ai-30sec-app
node tests/wage.test.js
```

全件通過すると `全テスト通過 ✅` と表示され、終了コードは 0 になります。
1件でも失敗すると終了コード 1 で終わります。

### 2. ブラウザで表示分岐を目視確認

`tests/test.html` を `file://` で開きます。
純粋関数テストの結果と、表示分岐（算出不能時に `NaN`/`Infinity`/`undefined` を出さないこと）の結果が緑で並べば OK です。

## ファイル責務

| ファイル | 責務 |
| -------- | ---- |
| `index.html` | UI 層。入力収集・結果描画・FP注記。計算式は持たない（`wage.js` を呼ぶだけ） |
| `wage.js` | 計算ロジック（純粋関数 `calcHourlyWages`）。唯一の実装。DOM・window 状態に触れない |
| `tests/wage.test.js` | 純粋関数の値検証テスト。node からも `<script>` からも動く。自前 assert（許容誤差 1e-6） |
| `tests/test.html` | ブラウザ簡易テストランナー。純粋関数テスト＋表示分岐の検証 |
| `REQUIREMENTS.md` | 人間の成果物。何を・なぜ作ると決めたか（計算定義・振る舞い仕様・FP前提） |
| `README.md` | この入口。開き方・テスト手順・ファイル責務 |

## 設計メモ

計算ロジックは `index.html` に内蔵せず `wage.js` に外出ししています。
`index.html` とテストが同じ `wage.js` を読むことで、計算式が物理的に1か所だけになり、
「ツールとテストでロジックがずれる」事故を構造的に防いでいます。
